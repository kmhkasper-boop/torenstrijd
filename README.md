# 🏰 Torenstrijd

Een tapspel voor **twee spelers op één scherm** (tablet, telefoon of computer).

**Speel direct:** https://kmhkasper-boop.github.io/torenstrijd/

## Hoe speel je?
- ⚡ Tik op je grote knop (of ergens op jouw kant) om energie te maken.
- 🪖 Koop soldaten. Ze lopen naar de toren van de ander en vechten onderweg.
- 🏰 Maak de toren van de ander kapot om te winnen!

**Wie wint van wie?** 🛡️ Ridder wint van 🏃 Loper · 🏹 Boogschutter wint van 🛡️ Ridder · 🏃 Loper wint van 🏹 Boogschutter.

Hoe langer je speelt, hoe meer je kunt: Ridder, Boogschutter, Tapkracht + Molen, Muur, Bliksem, Genezen en de Reus.
Ook kun je oefenen tegen de computer (makkelijk, normaal of moeilijk).

Eén HTML-bestand, geen installatie nodig.
